Как это работает

Не распознаём объекты — описываем «нормальный тоннель» и ищем всё, что в него не вписывается

Каждые 100 мс кадр лидара проходит пять шагов. Выберите шаг.

Габарит поезда

Габарит из самих тоннелей — и запас на неуверенность геометрии

Контур — максимальное сечение, которое помещается в свободное пространство всех записей: контактный рельс на 1.22 м, край платформы ≥ 1.37 м, стены ≥ 1.48 м, свод 1.18 м на высоте 3.43 м. Перетащите точку и измените неуверенность σ — так детектор решает для каждой точки облака.

Неуверенность растёт с дальностью: у стен и рельсов меньше, чем в 150 м. Внутренний контур — габарит, сжатый на 2σ.

Логика решения

Три сигнала, как у светофора метро

Решение принимается в каждом кадре по объектам, подтверждённым трекером. Условия STOP выполняются одновременно.

СТОП

  • объект подтверждён: ≥ 3 обнаружений из 5 кадров
  • ≥ 2 точки внутри габарита, сжатого на 2σ, в измеренной в этом кадре геометрии
  • до 30 м — пройдены физические тесты; дальше — оценка ½·LGBM + ½·CatBoost ≥ 0.425 и нет крепления к оболочке
  • ЭГО-тест: объект приближается со скоростью поезда

Выход: дистанция, время до столкновения, размеры, положение.

ВНИМАНИЕ

  • объект у границы габарита (в пределах 2σ)
  • объект дальше измеренной геометрии пути
  • отклонён ансамблем или ЭГО-тестом
  • ещё не подтверждён (2 из 5)

Информирует систему поезда, не тормозит.

ПУТЬ СВОБОДЕН

  • кандидатов нет
  • выдаётся «путь проверен до X м»: горизонт видимости и измеренной геометрии, не дальше 200 м

На кривых X обычно 110–170 м: дальше путь закрыт стеной.

—

Порог наклона −0.35, нужно ≥ 4 м пробега. Стоящий поезд не отменяет ничего; обрыв одометрии сбрасывает доказательства. На исходных данных тест не изменил ни одного решения.

Модель

Роутер двух ансамблей ½·LightGBM + ½·CatBoost + ЭГО-тест поверх физики

Физика решает, где путь и что в габарите; ансамбль оценивает правдоподобие дальних кандидатов; ЭГО-тест отсекает то, что движется вместе с поездом.

Физический слой · без обучения

Геометрия и тесты

Ось, уклон, кривизна пути до 200 м с неопределённостью σ(x). Габарит с запасом 2σ. Гравитация, форма, стенка за объектом, вето оболочки, трекер 3 из 5.

Роутер · финальная

Два эксперта ½·LightGBM + ½·CatBoost

Кандидат на полу → эксперт по людям и коробкам (порог 0.425). Низом ≥ 0.5 м над рельсами → эксперт по парящим и висящим объектам, обученный на всех формах опасности (порог 0.45). Оба — среднее логитов, сглаживание по 5 кадрам; датасеты 1 + 2 без запечатанного блока.

Прежняя · v1

⅓·LightGBM + ⅓·CatBoost + ⅓·PI-MLP

С физически-информированной нейросетью, обучена только на датасете 1, порог 0.37. PI-MLP убран: вне фолда не дал прироста. На новой линии v1 давала 10.3 ложных остановки на км.

Генератор организаторов ставит объекты на плоскость в системе лидара, а путь идёт под уклон — объекты «парят» над рельсами. Поэтому мы обучили второго эксперта на всех формах опасности (парящие, висящие, лежащие на рельсах) и направляем к нему кандидатов, чей низ выше 0.5 м над рельсами. Два объекта, которые организаторы считают «за габаритом», дают у нас STOP: наш габарит — вагон шириной 2.7 м, их — судя по объектам ≈ ±1.15 м; это один параметр конфигурации.

Правила

Деление по записям и блокам. Соседние кадры почти одинаковы — случайное деление по кадрам было бы утечкой.

Метки не от детектора. Негативы новой линии доказаны проездом поезда через место тревоги; позитивы — лучевое моделирование с точным положением.

Честно: ЭГО-тест придуман после анализа ошибок B3; параметров, подогнанных к B3, у него нет, и на датасете 1 он не изменил ни одного решения.

Зачем синтетика

Чтобы измерить дальность и обучить ансамбль

В данных нет реальных препятствий дальше ~60 м, в датасете 2 — нет совсем. Человек или коробка вставляются лучевым моделированием: для каждого реального луча Pandar128 считается пересечение с объектом, всё вокруг остаётся реальной записью.

Синтетика есть только в инструментах оценки. ROS-узел ничего не добавляет: данные заказчика и скрытый тест обрабатываются как есть. В прототипе такие сценарии помечены оранжевым.

Ограничения

Что мы знаем о границах

300 м недостижимы для Pandar128: измеряемая дальность 200 м. Коробка 0.5 м на 160 м даёт 1–2 отражения — меньше, чем нужно, чтобы отличить её от шума. Реальных препятствий в данных — одна запись на ~55 м. Внезапный «рельс» на ~24 м без предыстории по движению неотличим от человека, шагнувшего на путь, — его мы не гасим.

Запуск

docker build → docker run → ros2 bag play → результат

Ubuntu 22.04 + ROS 2 Humble внутри образа, все зависимости ставятся при сборке. Входной топик и ось лидара определяются автоматически.

docker build -t tunnel_guard .
docker run --rm -v /path/to/bags:/data tunnel_guard ros2 launch tunnel_guard tunnel_guard.launch.py bag:=/data/doubleT_obstacle
docker run --rm -v /path/to/bags:/data tunnel_guard ros2 run tunnel_guard evaluate_bag --bag /data/doubleT_obstacle --out /data/results
docker run --rm tunnel_guard python3 -m pytest -q /ws/src/tunnel_guard/test
