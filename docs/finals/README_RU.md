`live_check.json` в корне — короткий прогон поставки, указанной в `../reproduction_lock.json`. Некоторые старые CSV/JSON/GUI-файлы сохранены для истории; первичный источник версии и условий — соответствующий сводный документ и CI. Закреплённые опубликованные образы и их отдельный тест находятся в [reproduction_lock.json](../reproduction_lock.json) и workflow reproduction.

Реальные независимые метки организаторов ожидаются. Синтетическая пыль, информационный dust-zone и реальный размеченный аэрозоль — разные сущности; нулевые синтетические СТОП не доказывают реальную нулевую частоту ложных тревог.
