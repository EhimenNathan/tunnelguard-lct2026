## Время и окружение

Облачный run [39004731113](https://github.com/EhimenNathan/tunnelguard-lct2026/actions/runs/39004731113), ROS ca407f5, native_geometry=True. p50/p95/p99 обработки **40.58/50.29/54.66 мс**. p99 межсообщенческого интервала **125.99 мс**. Полный callback p95 **71.41 мс**. Обработок >100 мс: 0 (поле относится к обработке, не всему callback). shutdown_clean=False: в Xvfb/Mesa сохраняется проблема завершения RViz после намеренной остановки; рабочий интервал прошёл без аварии.

Windows при параллельных тестах: p50 **195.39**, p95 **441.73**, p99 **644.11**, max **1351.61 мс**; >100 мс **4400/4413**. Этот загруженный ПК не выполнял 10 Гц. Облачный короткий тест не заменяет полную оценку на целевом железе.

C++/Numba: [native_benchmark.json](native_benchmark.json), максимальное абсолютное расхождение 0 на контрольном наборе. C++ не показал ускорения относительно прогретой Numba.
