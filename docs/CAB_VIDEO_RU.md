# Видео: три записи организаторов, вид из кабины

Новая демонстрация: **1920×1080, H.264 / yuv420p, 20 кадров/с в файле, 83,2 с, без звука**. Основная камера фиксирована относительно лидара и смотрит вперёд вдоль пути; она не облетает сцену и не перемещается к цели. Цвет точек соответствует высоте, измеренный габарит зелёный, экстраполяция фиолетовая. Рамки препятствий и расстояния взяты из сохранённого вывода детектора. Зоны аэрозоля показаны отдельно от СТОП.

| Глава | Начало в видео | Исходная запись |
|---|---:|---|
| Платформа | 00:00,00 | 0–38,500 с |
| Стрелка | 00:19,25 | 0–73,500 с |
| Тоннель | 00:56,00 | 0–54,400 с |

Исходник — `new_synth_data.zst`, синтетические записи организаторов. Для демонстрации используются 16 + 30 + 22 сохранённых облака из `web/data/new_synth_{platform,switch,tunnels}.json`. Между исходными облаками около 2,5 с; изображение удерживается до следующего сохранённого облака. Воспроизведение идёт 2× по времени, без интерполяции точек, добавления препятствий и выдуманных детекций. Частота MP4 20 кадров/с не является частотой исходных облаков или доказательством производительности детектора. Холодный старт показан с фактическим состоянием подтверждения. Последний кадр удерживается только до действительного конца соответствующей записи.

## Воспроизвести генерацию

Из корня репозитория, Python 3.10+:

```powershell
python -m pip install numpy pillow imageio imageio-ffmpeg
python tools/finals_cab_video.py web "TunnelGuard_Финал_2026.mp4"
```

Docker, ROS и распаковка больших архивов для генерации видео не нужны. Скрипт использует профиль `web/data/gauge_profile.json`, длительности `docs/finals/new_synth/summary.json` и функции шрифтов/проекции из `tools/finals_video.py`. На Windows применяется Segoe UI; на Linux требуется DejaVu Sans. Результат и три контрольных PNG пишутся рядом с выходным MP4; постер и JSON глав обновляются в `web/assets` и `web/data`.
